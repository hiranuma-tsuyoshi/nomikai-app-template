## 1. 設計方針

1. **3つの画面系を独立させる**
   司会者（PC）／参加者（スマホ）／会場スクリーン（大型モニター）で、必要な情報も操作も違う。共通化しない。

2. **参加者は「1つのURL・1つの画面」**
   状態が変わると同じURLのまま中身が切り替わる。参加者に画面遷移を意識させない。

3. **司会者は「進行」1画面に集約**
   出題・締切・公開・得点確定を1画面で完結させる。統合だけ別画面。

4. **会場スクリーンは読み取り専用**
   操作要素を置かない。ゲーム状態に自動追従し、司会者が切り替える。

5. **酔っていても操作できる**
   主要操作は1タップ。確認ダイアログを出さない。文字は16px以上。

6. **公開前の情報漏洩を画面設計で防ぐ**
   最終確認中は、参加者にも会場スクリーンにも回答内容を出さない。

7. **ビジュアルは `design.md` のDuolingoスタイル**
   白い紙面、丸い太字、緑と青のアクセント、12px角丸、2pxボーダー。影・グラデーションは使わない。

## 3. 画面遷移

### 3-1. 参加者

```
QR / コード
   ↓
 P-01 参加
   ↓
 P-02 登録（名前・チーム）
   ↓
 P-03 待機 ──────────────┐
   ↓ 開始                 │
 P-04 回答               │
   ↓ 送信                 │
 P-05 回答完了            │
   ↓ 締切                 │
 P-06 最終確認（30秒）     │
   ↓ 公開                 │
 P-07 結果                │
   ↓ 次のお題              │
 P-04 回答 ───────────────┘
   ↓ 最終お題
 P-07 結果（最終）
```

- P-08（スリープ・復帰）は P-03／P-05 から開ける
- P-09（エラー）は任意の画面から表示される

### 3-2. 司会者

```
H-01 ログイン
   ↓
H-02 ホーム
   ↓
H-03 ルーム設定
   ↓
H-04 待機ロビー
   ↓ 開始
H-05 進行管理 ──→ H-06 グループ統合
   ↑  │                  │
   │  └──────────────────┘
   │ お題管理
   ▼
H-07 お題管理
   ↓ 最終お題
H-08 結果・順位
   ↓
H-09 操作ログ（任意）
```

- H-07 は H-05／H-06 のヘッダーから開く。ゲーム進行とは独立して編集できる。

### 3-3. 会場スクリーン

```
S-01 待機
   ↓ 開始
S-02 お題（回答受付中）
   ↓ 締切・最終確認（S-02のまま）
S-03 回答公開
   ↓ 統合・得点確定
S-04 得点発表
   ↓ 次のお題
S-02 お題
   ↓ 最終お題
S-05 最終結果
```

スクリーンは独立して操作できない。ゲーム状態に追従する。

## 4. 状態と画面の対応

| ゲーム状態 | 司会者 | 参加者 | 会場スクリーン |
|---|---|---|---|
| WAITING | H-04 | P-01／P-02／P-03 | S-01 |
| READY | H-04 | P-03 | S-01 |
| ANSWERING | H-05 | P-04／P-05 | S-02 |
| ANSWER_CLOSED | H-05 | P-05 | S-02 |
| FINAL_CHECK | H-05 | P-06 | S-02（**回答数のみ**） |
| REVEAL | H-06 | P-07 | S-03 |
| GROUPING | H-06 | P-07 | S-03 |
| SCORED | H-05／H-08 | P-07 | S-04 |
| FINISHED | H-08 | P-07 | S-05 |

> FINAL_CHECK 中に回答内容をスクリーンへ出すと、公開前に全員へ漏れる。
> この状態では「何人が回答済みか」だけを表示する。

### 5-3. H-05 進行管理（司会者）

```
┌───────────────────────────────────────────────────────┐
│ 進行管理   第3問 / 8        状態: 回答受付中          │
├───────────────────────────────────────────────────────┤
│ お題  朝ごはんといえば？                               │
│ 回答  18 / 30          残り 00:42 / 01:00             │
├───────────────────────────────────────────────────────┤
│ チームA  ●●●●●●  6/6   チームD  ●●●●○○  4/6       │
│ チームB  ●●●●●○  5/6   チームE  ●●●○○○  3/6 ⚠    │
│ チームC  ●●●●○○  4/6                                │
├───────────────────────────────────────────────────────┤
│ 自分の回答（チームA）  [ カレー          ]  [送信]    │
├───────────────────────────────────────────────────────┤
│ [回答を締め切る]   [お題をスキップ]   [中断]           │
└───────────────────────────────────────────────────────┘
```

- 回答数は「そのお題の回答者数 / チームの人数」
- 回答者4人未満のチームには⚠を付け、採点対象外であることを示す
- **司会者も選手**。自分の回答は進行画面から送信する
- 締切後は同じ画面が最終確認・公開・得点確定の操作に変わる
- 危険操作（スキップ・中断）は色を分ける

### 5-5. S-03 回答公開（会場スクリーン・例: 5チーム）

```
┌───────────────────────────────────────────────────────┐
│  第3問  朝ごはんといえば？                            │
├───────────────────────────────────────────────────────┤
│ チームA            │ チームB            │ チームC     │
│  カレー ×3         │  味噌汁 ×4         │  ごはん ×4  │
│  ごはん ×2         │  カレー ×1         │  パン ×1    │
│  パン ×1           │  納豆 ×1           │  うどん ×1  │
├───────────────────────────────────────────────────────┤
│ チームD            │ チームE                        │
│  カレー ×4         │  トースト ×3                   │
│  シリアル ×2       │  ごはん ×2                     │
│                    │  カレー ×1                     │

```

- 2〜6チームに対応。5チームは「3列＋2列」、6チームは「3列＋3列」の2段
- 7チーム以上は文字と列を自動で縮小する
- 統合された回答は「カレー（カレーライス統合）」のように表示

### 5-6. S-04 得点発表（会場スクリーン）

```
┌───────────────────────────────────────────────────────┐
│  第3問 結果                                           │
│                                                       │
│   チームA   +8    5/6人一致（83%）                    │
│   チームB  +10    6/6人一致（100%）                   │
│   チームC   +5    3/6人一致（50%）                    │
│   チームD   +7    4/6人一致（67%）                    │
│   チームE   +6    3/5人一致（60%）                    │
├───────────────────────────────────────────────────────┤
│  総合順位                                             │
│   1位 チームB   23pt                                  │
│   2位 チームA   21pt                                  │
│   3位 チームD   18pt                                  │
└───────────────────────────────────────────────────────┘
```

- 得点は「一致率×10」。人数が違うチームも同じ土俵で比べられる
- 得点はカウントアップで表示（0.5秒程度）
- 10点（全員一致）は強調表示
- 回答者4人未満のチームは「採点対象外」と表示する

### 5-7. S-05 最終結果（会場スクリーン）

```
┌───────────────────────────────────────────────────────┐
│ ゲーム終了  ルーム 4821                    全8問 8/8  │
│ 最終結果                                              │
│ 最終順位                                    5チーム   │
│ ┌───────────────────────────────────────────────────┐ │
│ │ 優勝                                              │ │
│ │ ● チームB                                  72pt   │ │
│ │ 全員一致 5回 ・ 最終お題 +10pt                    │ │
│ └───────────────────────────────────────────────────┘ │
│ 2位 チームA 68pt │ 3位 チームD 61pt │ 4位 ...        │
└───────────────────────────────────────────────────────┘
```

- 優勝は黄色の全幅カードにし、チーム名と累計ptを最も大きく表示する
- 2位以下は順位・チーム名・累計ptを横一列に並べる。2〜6チームに対応する
- 同点は「全員一致の回数 → 最終お題の得点 → 抽選」で順位を決める
- 最終順位は `ol` で表し、色だけで順位を伝えない

### 5-8. H-06 回答グループ統合（司会者）

```
┌───────────────────────────────────────────────────────┐
│ 進行管理   第3問 / 8        状態: グループ統合        │
├───────────────────────────────────────────────────────┤
│ お題  朝ごはんといえば？                               │
│ 統合できるのは同じチームの回答だけ                     │
├───────────────────────────────────────────────────────┤
│ [チームA 6人] [チームB 6人] [チームC 6人] [D] [E 5人] │
├──────────────────────────────┬────────────────────────┤
│ チームAの回答（3グループ）    │ 統合の状況             │
│ ┌────────────┐ ┌──────────┐ │ 回答グループ 3          │
│ │ □ カレー 4 │ │ □ ごはん1│ │ 統合済み 0              │
│ └────────────┘ └──────────┘ │ 選択中 0                │
│ ┌────────────┐              │                        │
│ │ □ パン   1 │              │ 得点を確定する          │
│ └────────────┘              │ 確定後は統合できない    │
│ 2つ以上選ぶと統合できます     │                        │
├──────────────────────────────┴────────────────────────┤
│ 統合後の回答名 [                    ]  0/20             │
│ 統合理由       [                    ]  0/40             │
│ [統合する]  [選択を解除]                               │
└───────────────────────────────────────────────────────┘
```

- 統合はタップで回答を選び、統合名と理由を入力して実行する（V-01決定）
- 統合できるのは同じチーム内だけ。チームを切り替えると選択は解除する
- 統合済みグループは理由と統合元を表示し、「取消」で統合前へ戻せる
- 統合理由は全チームに表示する
- 得点確定後は統合の追加・取消をロックする
- チームタブは2〜6チームに追従し、チーム数で等分する

### 5-9. H-07 お題管理（司会者）

```
┌───────────────────────────────────────────────────────┐
│ お題管理  全8問          8問 / 9分        [進行管理へ] │
├───────────────────────────────────┬───────────────────┤
│ お題一覧              [+ お題を追加] │ お題の設定        │
│ ┌───────────────────────────────┐ │ 問題数 8          │
│ │ 1 休日の過ごし方といえば？     │ │ 合計時間 9分      │
│ │   制限時間 60秒   [↑][↓][編集][削除] │ 最長 90秒       │
│ ├───────────────────────────────┤ │                   │
│ │ 2 好きな季節といえば？         │ │ 1〜100文字        │
│ │   制限時間 60秒   [↑][↓][編集][削除] │ 10〜600秒       │
│ ├───────────────────────────────┤ │ 上から順に出題    │
│ │ …                             │ │                   │
│ └───────────────────────────────┘ │ 保存について      │
│                                   │                   │
├───────────────────────────────────┴───────────────────┤
│ 追加・編集時: お題 / 文字数 / 制限時間 / 保存 / キャンセル │
└───────────────────────────────────────────────────────┘
```

- 一覧の上から順に出題する
- 追加・編集・削除・上下の並べ替えができる。削除は確認ダイアログを挟む
- お題は1〜100文字、制限時間は10〜600秒の整数
- 1440×900では8問が1画面に収まる。1366×768以下では一覧を縦スクロールする
- Supabase接続前はブラウザの `localStorage` に保存する

## 6. 表示・操作仕様

### 6-1. 文字と色

| 対象 | 仕様 |
|---|---|
| フォント（日本語） | M PLUS Rounded 1c（500／700／800） |
| フォント（英数字） | Nunito（500／700／800） |
| 参加者・司会者の本文 | 17px以上 |
| 参加者のお題 | 24px以上 |
| 会場スクリーンの本文 | 48px以上 |
| 会場スクリーンのお題 | 72px以上 |
| コントラスト比 | 4.5:1以上（大きな文字は3:1以上） |
| テーマ | ライトテーマ（Paper White `#ffffff`） |
| テキスト | Charcoal `#4b4b4b`、補助は Pencil Gray `#777777` |
| アクセント | Eager Green `#58cc02`、Spark Blue `#1cb0f6` |
| 角丸 | 12px |
| ボーダー | 2px |
| 影・グラデーション | 使わない |
| チームの識別 | 色＋チーム名＋アイコン。色だけで区別しない |

> Eager Green は白背景の本文にはコントラストが足りない（約2.1:1）。本文・見出しには濃い緑（`#3f8f00`／`#367a00`）を使い、`#58cc02` は塗り・進捗・強調に使う。詳細は9-4。
> 会場スクリーンはV-08で決定した「Kahoot!風ステージモード」（深紫背景＋鮮やかアクセント）を使う。参加者スマホ・司会者PCはライトテーマのまま。

### 6-2. 操作

- 主要操作は1タップ。確認ダイアログは出さない
- 送信は冪等キーで二重送信を防ぐ
- 送信後はボタンを無効化し、「送信済み」を表示
- 誤操作の取消は、締切前なら何度でも可能
- 参加者画面はスクロールなしで1画面に収める

### 6-3. タイマー

- 残り10秒で色を変える
- 0秒で自動的に次の状態へ
- 司会者画面には残り時間と経過時間の両方を表示

### 6-4. 会場スクリーン

- 16:9を基本とする
- 司会者PCの別ウィンドウ表示を第一候補。別端末でも可
- 操作要素を置かない。カーソルも隠す
- チーム数2〜6に対応する（7以上は自動で縮小）
- 接続が切れたら S-06 を表示し、自動復帰する

## 9. ビジュアルデザイン（Duolingoスタイル＋Kahoot!風ステージ）

`design.md` はマーケティングページのスタイルリファレンス。**レイアウトは持ち込まず、色・形・文字・イラストの考え方だけをゲームUIに適用する。**

### 9-1. 適用方針

- 白い紙面（Paper White）を基本にする
- 丸い太字（M PLUS Rounded 1c）で、子ども向け絵本のような親しみを出す
- 緑は「正解・一致・進捗」、青は「リンク・副次操作」に使う
- ボタン・カード・入力欄は12px角丸＋2pxボーダー
- 影・グラデーション・ガラス表現は使わない
- イラストは自作のマスコットのみ。Duolingoのフクロウ（Duo）やロゴ・画像は使わない
- 会場スクリーンだけはKahoot!風のステージモードにする（9-7）。スマホ・司会者PCはライトテーマのまま
- Kahoot!のロゴ・キャラクター・画像素材は使わない。参考にするのは参加体験と演出だけ

> `design.md` 内には「Eager Greenを主要CTAに昇格させるな」と「Primary CTAは緑塗り」が併記されている。
> 本アプリでは「一致＝正解」の意味を優先し、**主要ボタンは緑**を採用する。副次操作は青のアウトラインボタンにする。

### 9-3. タイポグラフィ

### 9-4. コントラストの調整

`design.md` の `#58cc02` は白背景に対して約2.1:1で、WCAGの本文基準（4.5:1）を満たさない。ゲームの可読性を優先し、以下に読み替える。

| 用途 | 参照値 | 採用値 | 理由 |
|---|---|---|---|
| 白背景の本文・見出し | `#58cc02` | `#3f8f00`（大見出し）／`#367a00`（本文） | コントラスト確保 |
| 緑ボタンの文字 | 白 | `#000437`（Night Ink） | 白文字は2.1:1。濃紺なら約10:1 |
| 青リンク | `#1cb0f6` | `#0b78b0` | 白背景で約4.8:1 |
| 緑の塗り・進捗・バッジ | `#58cc02` | そのまま | 面として使う分には問題ない |

> どうしても参照値の白文字・明るい緑を優先する場合は、18px以上の太字に限定し、会場スクリーンでは使わない。
> 数値はWCAG 2.xの相対輝度で計算した目安。実装時にコントラストチェッカーで再確認する。

### 9-6. マスコット

- **自作する。** Duolingoのフクロウ、ロゴ、イラスト素材は使用しない
- 案：丸い「伝心くん」（頭に思考の吹き出し）。チーム対抗なので2体並べてもよい
- 表情は「考え中」「ひらめいた」「一致した」「残念」の4種
- 画像はSVGで作り、色は9-2のトークンを使う
- マスコットは装飾。読み上げ・操作の代わりにしない

### 9-7. 会場スクリーンの扱い（V-08決定）

**案3「ハイブリッド」を採用する。**

| 画面 | テーマ | 理由 |
|---|---|---|
| 参加者スマホ | Duolingo風ライト（9-1〜9-6） | 酔っていても読みやすく、入力しやすい |
| 司会者PC | Duolingo風ライト＋進行UI | 長時間見ても疲れず、操作に集中できる |
| 会場スクリーン | **Kahoot!風ステージモード** | 暗い会場で眩しくなく、最後列から見える。盛り上がる |

#### ステージモードのトークン

| 用途 | トークン | 値 |
|---|---|---|
| 背景 | `--color-stage-bg` | `#1b0a3d`（深紫） |
| 面 | `--color-stage-surface` | `#2d1466` |
| 文字 | `--color-stage-fg` | `#ffffff` |
| 補助文字 | `--color-stage-muted` | `#c9b8ff` |
| 強調（ピンク） | `--color-stage-pink` | `#ff3b6b` |
| 強調（イエロー） | `--color-stage-yellow` | `#ffcc00` |
| 強調（シアン） | `--color-stage-cyan` | `#00c4ff` |
| 一致・正解 | `--color-stage-green` | `#58cc02` |

チーム色は9-2のA〜Fをそのまま使う。暗い背景ではチーム色を面で使い、文字は濃紺または白をコントラストで選ぶ。

#### ステージモードのルール

- 背景は深紫。白背景・ライトテーマは使わない
- 文字は白。補助はラベンダー。コントラスト比4.5:1以上を守る
- アクセントはピンク・イエロー・シアン・グリーンの4色まで。色を増やしすぎない
- 影・グラデーションは使わない。背景にフラットな円・三角・四角を薄く敷くのは可
- お題は72–120px（文字数に応じて自動調整）、得点・順位は96–140px、本文は48–56px
- タイマーは画面上部に大きく表示。残り10秒でピンク、0秒で赤
- 得点発表はチーム色の大きなカード＋カウントアップ。1位はイエローで強調
- ランキングは上位3チームを大きく、4位以下は小さく畳む
- 4択ボタンは使わない。うちは自由記述＋チーム一致率なので、Kahoot!のクイズUIは持ち込まない
- Kahoot!のロゴ・キャラクター・画像素材は使わない。参考にするのは「参加体験と演出」だけ
- マスコット「伝心くん」はステージでも使う。白フチを付けて背景から浮かせる
